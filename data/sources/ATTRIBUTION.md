# Sources of MDBridge's residue, atom-name, element and mass tables

`src/core/data_tables_independent.inc` is generated by `tools/gen_data_tables.py` only from the
extracts in this directory. Each subdirectory's README gives the exact files, retrieval dates and
fields kept.

| Source | Used for | Licence | Notice required |
|---|---|---|---|
| wwPDB Chemical Component Dictionary (components.cif, 2026-11-14), https://www.wwpdb.org/data/ccd | standard-residue atom names and their v2.3 spellings, protein backbone, nucleic atom sets, monatomic ion names, residues whose `HG`/`CL` atoms are Hg/Cl, guessable elements | CC0 1.0 | no (courtesy attribution) |
| wwPDB Atomic Coordinate Entry Format v3.3, https://www.wwpdb.org/documentation/file-format-content/format33/v3.3.html | standard nucleotide and water residue names; atom-name column rule | facts (guide © wwPDB, cited) | no |
| IUPAC-IUB JCBN, Nomenclature and Symbolism for Amino Acids and Peptides (1983), https://iupac.qmul.ac.uk/AminoAcid/ | the 20 amino-acid three-letter names, Sec, Pyl | facts | no |
| CIAAW (IUPAC), Abridged Standard Atomic Weights 2024, https://www.ciaaw.org/abridged-atomic-weights.htm | element symbols Z 1-118 and masses | facts | no |
| CIAAW, Radioactive elements (from NUBASE2020), https://www.ciaaw.org/radioactive-elements.htm | masses (mass numbers) of elements without a standard atomic weight | facts | no |
| Amber 2024 Reference Manual, https://ambermd.org/doc12/Amber24.pdf | Amber residue naming conventions (protonation states, termini, caps, nucleic ends, water models) | facts (manual cited, not copied) | no |
| GROMACS reference manual, https://manual.gromacs.org/current/ | GROMACS residue naming convention, SOL | facts (manual cited, not copied) | no |
| OpenMM 8.1.2 force-field XML and pdbNames.xml, https://github.com/openmm/openmm | Amber ff14SB / OL15 / OL3 and CHARMM36 residue names, nucleic heavy-atom names, ion and water atom names with elements, residue and atom-name aliases | MIT | yes: "Portions copyright (c) 2008-2019 Stanford University and the Authors", with the MIT permission notice |
